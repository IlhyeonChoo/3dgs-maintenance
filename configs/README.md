# Configs

이 디렉터리는 단계별 실험 설정 파일을 저장합니다.

## Naming Convention

- `<phase>.template.yaml`: 새 실험을 시작할 때 복사해서 사용하는 기준 템플릿
- `<phase>.<experiment-name>.yaml`: 실제 실험별 설정 파일

## Current Templates

- `partition.template.yaml`
- `train.template.yaml`
- `consolidation.template.yaml`
- `streaming.template.yaml`
